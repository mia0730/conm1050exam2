# CONM 1050 — Exam 2 Study Site

An interactive, visual study site for CONM 1050 (Intro to the Built Environment), Exam 2.

## Put it on GitHub Pages
1. Create a new repository on GitHub (it can be public or private with Pages enabled).
2. On the repo page click **Add file → Upload files** and drag in **everything in this folder** (`index.html`, `css/`, `js/`, `.nojekyll`, this README). Keep the folder structure — `index.html` must be at the top level.
3. Commit the upload.
4. Go to **Settings → Pages**, set **Source: Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
5. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

Tip: the `.nojekyll` file is hidden on Mac/Windows. If your file browser hides it, the site still works without it.

## What's inside
- **Home** — lesson tiles with progress
- **Exam 1 Review** — one-page refresher + Exam 1 flashcards and quiz
- **Learn** — six visual lessons (Transportation, Water, Energy, Modular, Building Operations, Real Estate) with clickable diagrams, calculators and mini-games
- **Flashcards** — flip cards, filter by lesson, mark "got it"
- **Quiz** — instant feedback, shuffled answers, retry the ones you missed
- **Math Lab** — endless practice for TDC, NOI, cap rate, payback, lifecycle cost and FCI

Progress (ticked sections, known cards, best quiz scores) is saved in the browser you use.
